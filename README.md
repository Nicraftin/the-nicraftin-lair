# Welcome to the Nicraftin Lair!
Hop on a voice call with a friend and try to beat this escape room as fast as you can.
Communication is key, you will need to share information with each other constantly.
Only talk though, because sending images or sharing your screen is not allowed.
The expected time of completion is between 2 and 3 hours, progress doesn't save.
